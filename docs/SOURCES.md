# Sources, credits & integrity

## Base code

**No repository was forked or used as a base.** This project was written from scratch (scaffold, agents, frontend, eval harness, scripts) with [Claude Code](https://claude.com/product/claude-code) under human direction. The full development history is in the public git log (~60 commits, each with a descriptive message). See the AI-usage disclosure in the [README](../README.md#ai-tool-usage-disclosure).

## External data sources

| Source | Used for | Access |
|---|---|---|
| **USITC Harmonized Tariff Schedule (2026)** | The tariff schedule we classify against; chapter/section notes; rate references. | Public USITC data, fetched by `scripts/fetch-hts.ts` into `data/hts/`. |
| **CBP CROSS (Customs Rulings Online Search System)** | Grounding the gold set — every gold answer is tied to a binding ruling on a materially similar product; the cross-verifier queries it live. | Public API at `rulings.cbp.gov` (`evals/tools/cross.sh`, `cross_batch.py`, `src/core/agents/cross-verifier.ts`). |
| **US Federal Register** | The regulatory watcher — recent CBP / USTR / USITC / Commerce documents, parsed for tariff impact. | Public API at `federalregister.gov/api/v1` (`src/core/agents/tariff-monitor.ts`). |
| **CBP FY2026 COBRA fee schedule (CBP Dec. 25-10)** | MPF min/max and rate, HMF rate. | Cited inline in `data/tariff-rates/2026.json` and the duty calculator. |

All tariff rates in `data/tariff-rates/2026.json` are a **demo subset** approximating published rates; production would pull the full USITC rate table. This is stated in the file and the README.

## Synthetic / representative data (clearly labeled)

- **Sample invoices** (`data/sample-invoices/`) and **sample entries** (`data/sample-entries/`) are synthetic, generated by `scripts/generate-sample-invoices.ts` and `scripts/generate-sample-entries.ts`. The entry generator plants known misclassifications with a `_ground_truth_correct_hts` field so the refund finder can be scored.
- The **ACE Importer Portal** in the Audit-broker demo is a faithful local replica (`src/core/lib/mock-ace-portal.ts`), not the live CBP portal. The UI describes the agent's behavior without claiming a live federal integration.
- The **Reg watch** tracked alerts are representative tariff actions matched to the demo catalog, shown separately from the genuinely live Federal Register feed.

## Integrity notes

- **Eval numbers are real**, produced by `npm run eval:classifier` and the report scripts; the surfaced summary (`evals/eval-summary.json`) is curated from those reports and cited back to them.
- **Limitations are disclosed**, not hidden — see the README "Known limitations" section and the per-report failure analyses in `evals/`.
- **The model's own identifier is never embedded** in committed artifacts; model names referenced (Sonnet 4.5, Opus 4.7) are the public product names used for the bake-off.
